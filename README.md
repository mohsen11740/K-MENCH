# K-MENCH | بازی منچ باران

بازی منچ کلاسیک با طراحی مدرن و الهام از نقش‌ونگار ایرانی.

- نام بازی: **K-MENCH**
- تیم: **بازی منچ باران**
- صاحب اثر: **باران عبدی**
- پلتفرم: وب، نصب‌پذیر به‌صورت PWA، آماده توسعه برای بسته‌بندی اندروید
- فناوری: React + TypeScript + Vite

## قابلیت‌های نسخه اولیه

- چهار جایگاه بازی و چهار مهره برای هر بازیکن
- انتخاب ۱ تا ۴ بازیکن انسانی و تکمیل جایگاه‌های دیگر با هوش مصنوعی
- تاس تصادفی، ورود با شش، زدن مهره حریف، خانه امن و مسیر پایانی
- رابط فارسی، راست‌چین و واکنش‌گرا
- نصب‌پذیری PWA و پوسته اولیه آفلاین
- ساخت کد دعوت و اشتراک‌گذاری از طریق امکانات اشتراک‌گذاری دستگاه

## اجرای محلی

```bash
npm install
npm run dev
```

## ساخت نسخه انتشار

```bash
npm run build
npm run preview
```

## وضعیت آنلاین و دعوت

بازی محلی و هوش مصنوعی در کنار بازی آنلاین چندنفره فعال هستند. میزبان می‌تواند اتاق بسازد و کد و لینک دعوت را به اشتراک بگذارد؛ بازیکنان با ورود به همان اتاق از طریق WebSocket به‌صورت زنده همگام می‌شوند. شروع بازی، انداختن تاس و حرکت مهره‌ها در سرور Durable Objects مدیریت و برای همه بازیکنان پخش می‌شود. آزمون خودکار دو بازیکن، ورود به اتاق، شروع بازی و همگام‌سازی حرکت مهره را پس از انتشار سرور بررسی می‌کند.

ارسال پیامک یا پیام در پیام‌رسان‌ها بدون اجازه کاربر انجام نمی‌شود؛ سیستم، برنامه مناسب را برای تأیید و ارسال در اختیار کاربر می‌گذارد.
